# DLBCSPJWD01

This is a submission for the IU Course DLBCSPJWD01 - a quiz app featuring questions on AI.

Dependencies:
- Python 3
- Pip packages: firebase_admin flask fpdf2

Installation:
- Download or clone repo
- Insert firebase_credential.json (provided separately) into the base folder
- Install dependencies (I've included a bash script for this purpose, `bash install.sh`, that works on my machine, your mileage will vary depending on OS)

Launch and testing:
- Run app.py (if you used install.sh: `.venv/bin/python3 app.py`)
- Open any web browser
- Go to http://127.0.0.1:5000
- Try the app
